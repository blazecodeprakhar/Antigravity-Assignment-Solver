# Workspace Instructions: Assignment Solver Protocol

When working on academic assignments in this workspace, follow these mandatory guidelines:

1. **NO CODE BOXES / NO TABLES FOR CODE**:
   - Never place solution code inside a table cell, boxed container, or shaded box.
   - Code must be added as plain text paragraphs using `Consolas` font (10.5 pt, 1.15 line spacing).

2. **ZERO COMMENTS IN CODE**:
   - Do not include any comment lines (`#`, `//`, `/* */`) in solution code files in `workspace/`.

3. **PRESERVE ORIGINAL PAGES 1-2**:
   - The original assignment text and instructions from `raw_file/*.docx` must remain completely untouched.
   - Append a Page Break before starting the solution sections.

4. **FAST AUTOMATED PIPELINE**:
   - Use `solve_assignment.py` to automate screenshot generation, code insertion, and document compilation.
